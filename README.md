# Дхарма-тулкит — опрос практикующих

Анонимный онлайн-опрос для буддийских практикующих (этап 1 UX-исследования проекта «Дхарма-тулкит»).
Часть схемы валидации: онлайн-опрос → глубинные интервью (см. UX-исследование, разделы 8.1–8.2).

**Демо**: `https://<username>.github.io/dharma-survey/`

## Что внутри

- 12 вопросов с **логикой ветвления** (В1–В12 из гайда валидации):
  - фильтр «практикую / интересуюсь / нет» → ветка новичка
  - блок школы только для Ваджраяны
  - вопросы о приложении-счётчике только при его использовании
  - уточнение расхождений календарных дат
  - финальный вопрос-вербовка волонтёров для интервью
- Дизайн в стиле проекта: тёмная тёплая тема, золото, Playfair Display + Inter
- Один вопрос на экран (мобильный сценарий — весь трафик из Telegram)
- Черновик ответов сохраняется в localStorage
- Без трекеров, аналитики и аккаунтов

## Сбор ответов

Статический сайт не умеет сохранять данные сам. Включите один из вариантов:

### Вариант 1 — Google Apps Script (рекомендуется, бесплатно)

1. Откройте [script.google.com](https://script.google.com) → Новый проект
2. Вставьте код:

```javascript
function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  const data = JSON.parse(e.postData.contents);
  const row = [new Date(data.ts)].concat(
    Object.entries(data.answers).map(([k, v]) => k + ": " + v)
  );
  sheet.appendRow(row);
  return ContentService.createTextOutput("ok");
}
```

3. Создайте связанную Google Таблицу (в редакторе: Триггеры/Ресурсы)
4. Разверните как Web App: Deploy → New deployment → Web app → доступ «Anyone»
5. Скопируйте URL развертывания в `SUBMIT_URL` в начале `index.html`
6. Закоммитьте и запушьте — ответы начнут падать в таблицу

### Вариант 2 — ручная отправка

Оставьте `SUBMIT_URL` пустым: на финальном экране респондент увидит скопированный
текст ответов и контакт Telegram для пересылки. Работает без настройки, но
повышает трение.

## Настройка

В начале `index.html` в блоке `КОНФИГУРАЦИЯ`:

- `SUBMIT_URL` — адрес приёмника ответов (см. выше)
- `CONTACT_TELEGRAM` — контакт команды, показывается респонденту
